# CodeBoard Mobile

## Описание

CodeBoard Mobile — мобильное приложение платформы CodeBoard, разработанное для смартфонов и планшетов.

## Технологии

- React Native
- TypeScript
- Expo
- Expo Router

## Основной функционал

- Авторизация и регистрация
- Лента постов
- Просмотр поста
- Создание постов
- Комментарии и лайки
- Поиск
- Коллекции
- OCR (распознавание кода по фото)

## Архитектура

- Expo Router (файловая навигация)
- Drawer + Tabs навигация
- Разделение экранов и компонентов

## Установка и запуск

```bash
npm install
npx expo start
```

## Переменные окружения

В app.json:

```
"extra": {
  "apiUrl": "http://localhost:3000"
}
```

## Особенности

- Поддержка камеры и галереи
- OCR через expo-text-extractor
